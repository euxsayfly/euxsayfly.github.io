### 前言
今天突然收到一个微信消息，标题是“公众号长时间未使用将被冻结” 看到时我愣了一下，心想我什么时候弄过微信公众号呀，于是便点进去一看   
{% asset_img 0.jpg %}  
原来是之前本科时弄的班级公众号，记得当时是为了评优秀班集体做的，然后评上了后就断更了...
今天若不是微信提醒，我已经快忘了这事了。于是我便进入这个公众号看了看，一共就两篇文章，一篇是当时的班主任在教师节前给我们上了个班会，一篇是班级聚餐，然后就没了。  
{% asset_img 2.jpg %}   
笑死，看来当时我们根本没想着把这公众号经营下去。现在账号要冻结了，我就想着还是把这两篇文章给保存下来吧，好歹也是点纪念。
### SingleFile
在网上搜了搜如何实现，基本分为两类，一种是下载那种软件（都号称一键采集，但大部分要付费），还有一种便是利用Python爬虫抓包，当然这两种方法都适用于大量的导出。我这次只需要导出两篇文章即可，没必要这么麻烦，然后我就发现了这个-SingleFile。
这是个Chrome扩展,可以将一个完整的页面保存到单个HTML文件中，下面是其链接：  
<https://chrome.google.com/extensions/detail/mpiodijhokgodhhofbcjdecpffjipkle>  
扩展程序的安装我这里就不赘叙了  
{% asset_img 1.jpg %}   
接下来我就以上面提到的这两篇公众号文章为例介绍一下用法，首先点进去然后用Chrome浏览器打开文章
{% asset_img 3.jpg %} 
然后在浏览器中直接右键就可以保存了  
{% asset_img 4.jpg %}  
接着便生成了一个html单文件，外部css、js、image会转为base64（根据需要）嵌入到html中，方便保存。  
{% asset_img 5.jpg %}   
再用浏览器打开这个文件，图片和样式都还在。  
{% asset_img 6.jpg %}   
另外一篇也这么操作也就行了。  
{% asset_img 7.jpg %}
